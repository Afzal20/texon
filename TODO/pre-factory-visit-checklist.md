# Pre-Factory-Visit Checklist (End of Week 1)

> Historical plan — superseded on 2026-10-13. Follow the [Odoo-powered product scope](../docs/GARMENT_ERP_13_MODULES_MASTER_PLAN.md) and [current milestone roadmap](../docs/integration_design/04-200-commit-implementation-roadmap.md). The instructions and estimates below are retained for context, not execution. Dedicated cutting/CAD, device integration, specialist optimization, and duplicate ERP engines are excluded.

Demo-ready criteria before visiting a factory.

---

- [ ] Can demo login with 3 different roles (show different menus)
- [ ] Can create a buyer and a PO with size/color matrix
- [ ] Can create a style with BOM
- [ ] Can explode BOM → show material requirements
- [ ] Can show stock balance and a stock movement history
- [ ] Can create a production order → show CPM timeline
- [ ] Can run RPWM → show workstation assignments
- [ ] Can enter daily production and see efficiency %
- [ ] Can run QC inspection → show DHU
- [ ] Can show LP optimizer assigning orders to lines
- [ ] Dashboard shows at least 4 real KPI numbers
- [ ] App works on mobile browser
- [ ] App is deployed (not localhost) → shareable URL
